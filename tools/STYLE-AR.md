# 《恨长沙》阿拉伯语译本风格底本（ضائع في تشانغشا / AR）

> 与 `STYLE-EN.md` 同源，做阿拉伯语适配。中文原文为唯一真源：`chapters/henchangsha/<num>.json`。
> 全篇 RTL，专名用阿拉伯字母音译，不夹拉丁字母（SAR / NETD 等缩写除外，保持拉丁原形）。

## 0. 目标

阿拉伯语读者读到的是一部**书店里能卖的中国当代长篇小说**：句子清楚、节奏偏短、对白自然，
用现代标准阿拉伯语（فصحى معاصرة），不用古典修辞堆砌，不写新闻体。

## 1. 硬性结构规则

1. **段落一一对应**：中文 N 段 → 阿拉伯语 N 段，不合并不拆分不增删。
2. 章标题：`مقدمة: كون بنغ`、`الفصل الأول: البومة`、`الفصل الثاني: غوانغوان`……
   序数用 الأول، الثاني، الثالث … الرابع والأربعون。
3. 标点用阿拉伯标点：`« »` 引号、`،` 逗号、`؛` 分号、`؟` 问号、`…` 省略号、`—` 破折号。
   句末用 `.`（不用 `۔`）。
4. 数字用西方阿拉伯数字（1986、51%），金额 `يوان`（`مليون يوان`）。绝不换成第纳尔/美元。
5. 成语俗语译意不译形；不加「在中国……」式旁白解释。

## 2. 文体细则

- 句子 10–18 词；中文逗号长串拆成短句，用 `؛` 或句号断开。
- 不用被动堆叠；避免名词化（`القيام بـ` 少用）。
- 对白：中年男人之间可用口语化措辞（但仍用 فصحى），不写方言；体制内场合用敬语（`حضرتك`）。
- 不补写心理、不加比喻；中文有的细节一个不丢。
