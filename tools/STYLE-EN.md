# 《恨长沙》英文译本风格底本（Lost in Changsha / EN）

> 本文件是英文全本的唯一风格标准。任何人（或任何一轮翻译）动笔前必须先读这一份，
> 不得各自发挥。中文原文为唯一真源：`chapters/henchangsha/<num>.json`。

## 0. 一句话目标

写成一本**海外书店里能卖的中国当代小说**：读起来像原本就用英文写的，句子短、动作实、
对白有人味；不端着、不学术、不逐字搬运中文句法。

参考气质：Ha Jin 的克制叙事、 translated Chinese literary commercial fiction 的可读性
（不是文学奖体，也不是网文腔）。

## 1. 硬性结构规则

1. **段落一一对应**：中文 N 段 → 英文 N 段，顺序不变。不合并、不拆分、不增删。
   中文里单独成段的短句（如「张靖雨的确是个大美女。」）英文也必须单独成段。
2. 每章末尾不得加译者注、总结、前言。
3. 章标题格式：`Chapter One: The Owl`（序章 `Prologue: Kunpeng`；数字用英文单词，
   One…Forty-Four）。
4. 引号用弯引号 `“ ”` 与 `‘ ’`；省略号用 `…`；破折号用 `—`（em dash），不用 `--`。
5. 数字：叙事里用阿拉伯数字（1986、2012、51%、2 million yuan）。
   口语里成句的数字可用词（“twenty-four hours”）。
6. 货币保留人民币：`yuan`、`million yuan`、`1.5 billion yuan`。绝不换成美元。
7. 中文成语、俗语、歇后语**译意不译形**：写出它在场景里真正干的事，
   必要时用一个英文里同样有力的短句替代，不硬造中式比喻。

## 2. 文体细则（好读风）

- **句子**：平均 12–18 词。长句拆开；中文的逗号串改成英文的句号或分号。
- **动词优先**：少用 `there is / the fact that / the realization that`；
  少用抽象名词化（`the improvement of` → `he improved`）。
- **被动语态克制**：只有施动者不明或确实需要时才用。
- **对白**：允许缩写（don't / I'm / gonna 视人物而定）。中年男人酒桌/饭局说话可以粗一点、
  短一点；体制内场合保持克制和客气；不出现英式古语、不出现脏话堆砌。
- **叙述视角**：第三人称限知（跟中文一致），不跳视角、不补写人物心理。
- **不解释中国文化**：不写“in China, people usually…”这类导游腔。需要读者懂的地方，
  让人物在对话里自然带出（例：`“Lao Zheng”?` → `Old Zheng — the name everyone had used
  since his thirties.`）。
- **不加戏**：中文没有的画面、比喻、内心活动，不许自己加。中文有的细节，不许丢。

## 6. 神兽小传（bio）译法

- 结构：`“Name” — <出处/释名>。<一句形貌>。<一句暗扣本章人物处境，不点破情节>。`
- 《山海经》→ `the Classic of Mountains and Seas`；《庄子·逍遥游》→
  `Zhuangzi's “Free and Easy Wandering”`。
- 凡中文原文注明“不见于确切经文”“异兽”处，英文照实写，**不得虚构经名或篇名**。
- 语气克制、半文半白，一句话里不要堆形容词。

## 7. 交稿前自检（缺一不可）

1. `paragraphs` 长度 === 中文段数。
2. 每段非空、无残留中文（专名注音除外，本译本不加注音）。
3. 人名、称呼、神兽名、机构名与本节表一致。
4. 数字、金额、百分比与中文一致。
5. `chars` = 全部段落字符数之和（含空格）。
6. JSON 可被 `json.load` 解析，键顺序：work, num, lang, languageLabel, direction,
   title, sourceTitle, beast, bio, paragraphs, paragraphCount, chars。
